# Responsive Website Using CSS Media Queries

## Project Overview

This project demonstrates how to convert a desktop-only webpage into a fully responsive and mobile-friendly website using CSS Media Queries.

The webpage automatically adjusts its layout, font sizes, navigation menu, and content structure based on different screen sizes such as desktops, tablets, and mobile devices.

---

## Objective

The main objective of this project is to:

- Create a responsive webpage layout
- Improve mobile user experience
- Learn and apply CSS Media Queries
- Build flexible layouts using Flexbox
- Ensure images and content adapt properly on smaller screens

---

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Media Queries
- VS Code
- Chrome DevTools

---

## Features

### Responsive Navigation Bar
- Navigation links are displayed horizontally on desktop screens
- Navigation links stack vertically on smaller screens

### Responsive Hero Section
- Desktop view shows text and image side-by-side
- Mobile view stacks content vertically

### Flexible Image Handling
- Images automatically resize according to screen size

### Responsive Cards Layout
- Cards appear in a row on desktop
- Cards stack vertically on mobile devices

### Mobile Optimization
- Reduced font sizes for smaller screens
- Improved spacing and alignment
- Prevented horizontal scrolling issues
